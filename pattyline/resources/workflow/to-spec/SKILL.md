---
name: to-spec
description: Turn a confirmed decision frontier into a specification in a fresh session.
---

Read the handoff, confirmed decisions, open questions, glossary/ADR drafts and
authoritative documents. Trace every confirmed requirement to observable behavior
and acceptance evidence in spec.md. Include boundaries, configuration, lifecycle,
failure handling, verification, security and external prerequisites. Label
inferences as proposals and return unresolved product choices to the human.

Complete only when every settled decision is covered and contradictions are
resolved. Return a nonempty spec.md artifact and remaining questions using the
supplied response template. The next breakdown stage starts in a fresh session.
