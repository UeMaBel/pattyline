---
name: handoff
description: Preserve a preparation frontier before stage changes, interruptions or context limits.
---

Write approved decisions, settled terms, open questions, authoritative paths,
evidence references and exact stage progress to the durable handoff. Preserve
unresolved choices verbatim. Confirm the file exists before requesting a fresh
session. A fresh context uses a new runtime session identity; resuming the old
session does not satisfy a stage boundary. The receiving stage reads the handoff
and authoritative sources, then reports contradictions before drafting.
